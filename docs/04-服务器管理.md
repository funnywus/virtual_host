# 服务器管理

服务器管理模块是系统的核心基础设施，所有子域名、FTP、Nginx、SSL 操作都依赖已配置的 SSH 服务器。

## 功能概览

- 添加 / 编辑 / 删除 Linux 服务器
- SSH 连接测试（密码或密钥）
- 浏览器内 SSH 终端（Xterm.js）
- 服务器到期时间（`expire_at`）与状态管理
- 标签分类与筛选
- SSH 连接池复用，提升批量操作性能

## 添加服务器

在管理后台 **服务器管理** 页面填写：

| 字段 | 说明 |
|------|------|
| 名称 | 便于识别的别名 |
| IP 地址 | 服务器公网或内网 IP |
| SSH 端口 | 默认 22 |
| 用户名 | SSH 登录用户（通常为 root 或有 sudo 权限的用户） |
| 密码 | SSH 密码（加密存储） |

添加后点击「测试连接」验证 SSH 是否可达。

## SSH 终端

系统内置 Web 终端组件（`ServerTerminal.vue`），通过后端 SSH 连接在浏览器中执行命令，适用于：

- 快速查看 Nginx 状态
- 手动排查文件权限问题
- 临时执行运维命令

> 终端会话通过后端代理，请勿在终端中执行不可信脚本。

## 标签管理

标签用于对多台服务器分组，便于在子域名创建、批量 SSL 等场景按组筛选。

- 在 **标签管理** 页创建标签（名称、颜色）
- 创建服务器或子域名时可关联标签
- 支持设置默认筛选标签

相关 API：`/api/tags`

## 到期与状态

服务器支持以下扩展字段（启动时自动迁移）：

- `expire_at` — 到期时间，用于提醒与批量检查
- `status` — 状态（如 `active`），停用后相关操作会受限

子域名到期检查任务会联动 DNS 平台自动清理过期记录。

## SSH 连接池

`backend/utils/ssh-connection-pool.js` 维护 SSH 连接池：

- 同一服务器多次 SFTP/命令操作复用连接
- 减少 TCP 握手与认证开销
- 批量文件操作、SSL 部署时显著提升速度

## API 参考

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/servers` | 获取服务器列表 |
| POST | `/api/servers` | 添加服务器 |
| PUT | `/api/servers/:id` | 更新服务器 |
| DELETE | `/api/servers/:id` | 删除服务器 |
| POST | `/api/servers/:id/test` | 测试 SSH 连接 |

## 安全建议

1. 使用专用运维账号，避免直接使用 root（若业务允许）
2. 定期轮换 SSH 密码
3. 限制管理后台访问 IP（通过 Nginx 或防火墙）
4. 服务器凭证存储在数据库中，务必保护数据库文件或 MySQL 访问权限

## 故障排查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 连接超时 | 防火墙未开放 22 端口 | 检查安全组/iptables |
| 认证失败 | 用户名或密码错误 | 重新测试 SSH 登录 |
| SFTP 操作慢 | 网络延迟或连接未复用 | 检查连接池日志，确认服务器负载 |
| 终端无响应 | SSH 会话断开 | 刷新页面重新打开终端 |
