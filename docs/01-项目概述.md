# 项目概述

## 简介

**虚拟主机管理系统**（Virtual Host Manager）是一套面向运维与建站场景的全栈管理平台。系统通过 Web 界面统一管理多台 Linux 服务器、域名解析、SSL 证书、Nginx 配置与 FTP 文件操作，降低虚拟主机批量运维的复杂度。

当前版本：**v2.0.0**

## 核心能力

| 模块 | 说明 |
|------|------|
| 用户认证 | JWT 登录、角色区分（admin / user） |
| 服务器管理 | SSH 连接、在线终端、连接池、到期提醒 |
| 域名与子域名 | 主域名绑定 DNS 平台，子域名一键创建与批量操作 |
| DNS 解析 | 支持阿里云、腾讯云 DNS API |
| SSL 证书 | Let's Encrypt 等证书申请、续期、批量签发 |
| Nginx | 虚拟主机配置生成、同步、请求限流 |
| FTP / 文件 | SFTP 文件管理、网页上传、分片上传、压缩解压 |
| 标签分类 | 服务器标签筛选与分组 |
| 公开上传页 | 面向终端用户的授权码上传入口 |

## 技术栈

### 后端

- **Node.js + Express** — REST API 与静态资源服务
- **SQLite3 / MySQL** — 双数据库支持，可迁移
- **SSH2** — 远程服务器连接与 SFTP
- **JWT + bcrypt** — 身份认证与密码加密
- **WebSocket** — SFTP 代理、SSL 日志推送
- **Multer** — 大文件上传处理

### 前端

- **Vue 3 + Composition API**
- **Element Plus** — UI 组件库
- **Vue Router + Pinia** — 路由与状态管理
- **Monaco Editor** — 在线代码编辑
- **Xterm.js** — 浏览器内 SSH 终端
- **Vite** — 构建与开发服务器

## 项目结构

```
virtual_host/
├── backend/          # Node.js 后端
│   ├── db/           # 数据库适配（SQLite / MySQL）
│   ├── routes/       # API 路由
│   ├── services/     # 业务服务（DNS、SSL、Nginx、SFTP 等）
│   ├── middleware/   # 认证中间件
│   ├── scripts/      # 初始化、迁移、清理脚本
│   ├── templates/    # PHP 直传等模板
│   └── server.js     # 入口
├── frontend/         # Vue 3 前端
│   └── src/
│       ├── views/    # 页面
│       ├── components/
│       ├── api/      # 接口封装
│       └── stores/   # Pinia 状态
└── docs/             # 项目文档（本目录）
```

## 访问入口

| 入口 | 路径 | 说明 |
|------|------|------|
| 公开上传页 | `/` | 授权码验证后上传文件 |
| 管理后台登录 | `/admin-jm/login` | 管理员/用户登录 |
| 管理后台 | `/admin-jm/*` | 需登录后访问 |
| 后端 API | `/api/*` | REST 接口 |
| 健康检查 | `/api/health` | 服务状态 |
