# 快速开始

本文档帮助你在本地或服务器上快速运行虚拟主机管理系统。

## 环境要求

- **Node.js** >= 14.x（推荐 18+）
- **npm** >= 6.x 或 **pnpm**
- **MySQL 5.7+**

## 安装步骤

### 1. 克隆项目

```bash
git clone <repository-url>
cd virtual_host
```

### 2. 安装后端依赖

```bash
cd backend
npm install
```

### 3. 配置环境变量

在 `backend/` 目录创建 `.env` 文件：

```env
# 服务端口（默认 3000，开发环境常用 6002）
PORT=6002

# JWT 密钥（必填，请使用随机长字符串）
JWT_SECRET=your_jwt_secret_key_here

# MySQL
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_USER=virtual_host
MYSQL_PASSWORD=your_password
MYSQL_DATABASE=virtual_host
```

### 4. 初始化管理员账号

```bash
cd backend
node scripts/init-admin.js [用户名] [密码] [邮箱]

# 使用默认值
node scripts/init-admin.js
# 默认: admin / admin123 / admin@example.com
```

或使用 npm 脚本：

```bash
npm run create-admin
```

### 5. 启动后端

```bash
# 开发模式（nodemon 自动重启）
npm run dev

# 生产模式
npm start
```

也可使用项目根目录脚本：

```bash
./start-backend.sh
```

启动成功后控制台会输出类似：

```
Server running on port 6002
WebSocket SFTP Proxy available at ws://localhost:6002/ws-upload
```

验证服务：

```bash
curl http://localhost:6002/api/health
# {"status":"ok"}
```

### 6. 安装并启动前端

```bash
cd ../frontend
npm install
npm run dev
```

前端开发服务器默认运行在 **http://localhost:5173**，API 默认指向 `http://localhost:6002`（见 `frontend/src/config.js`）。

### 7. 生产构建

```bash
cd frontend
npm run build
# 构建产物输出到 backend/public，由后端统一提供静态资源
```

生产模式下访问同一端口即可（如 `http://your-server:6002/admin-jm/login`）。

## 首次登录

1. 打开 **http://localhost:5173/admin-jm/login**（开发）或 **http://localhost:6002/admin-jm/login**（生产）
2. 使用初始化时创建的管理员账号登录
3. 建议登录后立即在「设置」中修改默认密码

## 推荐初始化顺序

1. **DNS 平台** — 在「DNS 平台」页添加阿里云/腾讯云 API 密钥
2. **服务器** — 在「服务器管理」添加 SSH 服务器并测试连接
3. **主域名** — 在「域名管理」绑定主域名与 DNS 平台
4. **子域名** — 创建子域名，系统自动写入 DNS 与 Nginx
5. **FTP 账号** — 为子域名创建 FTP，供文件上传使用

## 常见问题

### 端口被占用

```bash
# 查看占用进程
lsof -i :6002

# 停止旧进程（start-backend.sh 会自动处理）
lsof -ti :6002 | xargs kill -9
```

### 上传临时文件堆积

```bash
cd backend
node scripts/cleanup-temp.js
```

### 前端无法连接后端

- 确认后端已启动且端口与 `frontend/src/config.js` 中 `API_BASE` 一致
- 开发环境可通过环境变量覆盖：`VITE_API_BASE=http://localhost:6002`

更多故障排查见根目录 [TROUBLESHOOTING.md](../TROUBLESHOOTING.md)。
