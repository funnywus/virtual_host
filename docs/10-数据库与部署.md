# 数据库与部署

本文档介绍数据库选型、迁移、生产部署与日常运维。

## 数据库

系统使用 **MySQL**，入口：`backend/db/database.js` → `database-mysql.js`。

### MySQL 配置

```env
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_USER=virtual_host
MYSQL_PASSWORD=your_password
MYSQL_DATABASE=virtual_host
```

也兼容 `DB_HOST` / `DB_USER` / `DB_PASSWORD` / `DB_NAME`。

## 主要数据表

| 表名 | 说明 |
|------|------|
| `users` | 用户账号 |
| `servers` | SSH 服务器 |
| `domains` | 主域名 |
| `subdomains` | 子域名 |
| `dns_records` | DNS 记录 |
| `aliyun_config` | DNS 平台 API 配置 |
| `virtual_hosts` | 虚拟主机（历史/兼容） |
| `server_tags` | 服务器标签 |
| `batch_ssl_jobs` | 批量 SSL 任务 |

子域名表包含 Nginx 同步、SSL 状态、限流等扩展字段。

## 自动迁移

后端启动时在 `server.js` 执行 `migrateDatabase()`：

- 检测缺失字段并 `ALTER TABLE` 补充
- 自动创建 `batch_ssl_jobs` 等新增表
- **幂等设计** — 重复启动不会报错

常见自动添加字段：

- `domains.expire_at`
- `servers.expire_at`、`servers.status`
- 子域名限流相关字段

## 生产部署

### 推荐架构

```
[Nginx 反向代理 + HTTPS]
         │
         ▼
[Node.js 后端 :6002]
         │
    ┌────┴────┐
    ▼         ▼
 MySQL    Linux 服务器群（SSH）
```

### 部署步骤

1. **构建前端**

```bash
cd frontend
npm install
npm run build
# 输出到 backend/public/
```

2. **配置环境变量**

在 `backend/.env` 设置 `PORT`、`JWT_SECRET`、`MYSQL_*` 等。

3. **初始化数据库与管理员**

```bash
cd backend
npm install --production
node scripts/init-admin.js
```

4. **启动后端**

```bash
npm start
# 或使用 pm2
pm2 start server.js --name vhost-manager --node-args="--max-old-space-size=2048"
```

5. **配置反向代理（可选）**

```nginx
server {
    listen 443 ssl;
    server_name admin.example.com;

    location / {
        proxy_pass http://127.0.0.1:6002;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 1800s;
        client_max_body_size 500m;
    }
}
```

> 大文件上传需调大 `client_max_body_size` 与 `proxy_read_timeout`。

### 进程管理

推荐使用 **pm2** 或 **systemd** 守护进程：

```bash
pm2 save
pm2 startup
```

重启脚本：`./restart-backend.sh`

## 备份策略

| 对象 | 建议 |
|------|------|
| MySQL | mysqldump 定时备份（或后台「系统备份」） |
| 环境变量 | 安全存储 `.env`，不纳入 git |
| 服务器 SSH 凭证 | 数据库含密码，备份需加密 |

## 日志与监控

- 应用日志：stdout（pm2 logs / journalctl）
- SSL 检查：`[SSL Check]` 前缀
- 到期检查：`[Expire Check]` 前缀
- 数据库迁移：`[DB Migration]` 前缀
- 健康检查：`GET /api/health`

## 定期维护

```bash
# 清理上传临时分片（建议 cron 每日执行）
cd backend && node scripts/cleanup-temp.js

# 检查磁盘空间（temp、public、data 目录）
df -h
```

## 故障排查

### 数据库连接失败

```bash
mysql -h 127.0.0.1 -u virtual_host -p virtual_host
```

### 内存不足

后端已设置 `--max-old-space-size=2048`。若合并超大文件仍 OOM，考虑增大限制或改用 SFTP 直传。
