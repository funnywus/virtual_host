# 到期时间功能修复

## 问题
保存了到期时间但不显示，需要显示剩余天数。

## 修复内容

### 1. 后端修复 ✅

#### backend/routes/dns.js
- **添加域名接口** - 添加 `expire_at` 字段到 INSERT 语句
- **更新域名接口** - 添加 `expire_at` 字段到 UPDATE 语句

#### backend/routes/servers.js
- **添加服务器接口** - 添加 `expire_at` 字段到 INSERT 语句
- **更新服务器接口** - 添加 `expire_at` 字段到 UPDATE 语句

### 2. 前端优化 ✅

#### frontend/src/views/Domains.vue
- **显示优化**
  - 第一行：到期时间（YYYY-MM-DD HH:mm:ss）
  - 第二行：剩余天数文本
  - 未设置显示"永久"

- **新增函数**
  - `getExpireDaysText()` - 获取剩余天数文本

#### frontend/src/views/Servers.vue
- **显示优化**
  - 第一行：到期时间（YYYY-MM-DD HH:mm:ss）
  - 第二行：剩余天数文本
  - 未设置显示"永久"

- **新增函数**
  - `getExpireDaysText()` - 获取剩余天数文本

## 显示效果

### 到期时间列显示
```
2024-12-31 23:59:59
还剩 30 天
```

### 剩余天数文本规则
- `已过期 X 天` - 已经过期
- `今天到期` - 当天到期
- `明天到期` - 明天到期
- `还剩 X 天` - 正常状态

### 颜色规则
- 🔴 **红色** (#FF3B30) - 已过期
- 🟠 **橙色** (#FF9500) - 7天内到期
- 🟡 **黄色** (#FFCC00) - 30天内到期
- 🟢 **绿色** (#34C759) - 正常（30天以上）
- ⚪ **灰色** (#909399) - 永久

## 数据库字段

确保数据库表已添加 `expire_at` 字段：

```sql
-- domains 表
ALTER TABLE domains ADD COLUMN expire_at DATETIME DEFAULT NULL;

-- servers 表
ALTER TABLE servers ADD COLUMN expire_at DATETIME DEFAULT NULL;
```

## 测试步骤

1. **添加域名/服务器**
   - 填写基本信息
   - 选择到期时间
   - 保存

2. **查看列表**
   - 检查到期时间是否显示
   - 检查剩余天数是否正确
   - 检查颜色是否正确

3. **编辑域名/服务器**
   - 修改到期时间
   - 保存后检查是否更新

4. **清空到期时间**
   - 清空日期选择器
   - 保存后应显示"永久"

## 注意事项

1. **时区问题**
   - 前端使用本地时区
   - 后端存储时注意时区转换

2. **剩余天数计算**
   - 使用 `Math.ceil()` 向上取整
   - 确保当天到期显示"今天到期"

3. **颜色提示**
   - 红色和橙色需要及时处理
   - 黄色需要提前准备续费

4. **数据验证**
   - 后端应验证日期格式
   - 前端使用日期选择器确保格式正确
