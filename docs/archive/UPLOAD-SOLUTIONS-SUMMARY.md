## 🚀 方案一：压缩包上传（最快）

### 性能数据

| 文件数 | 原始大小 | 压缩后 | 传统上传 | 压缩包上传 | 提升 |
|--------|---------|--------|---------|-----------|------|
| 1000 | 200MB | 50MB | 15分钟 | 1分钟 | **15x** ⚡ |

### 三步操作

```bash
# 1. 压缩
zip -r website.zip . -x "*.git*" "node_modules/*"

# 2. 上传（拖拽到网页）

# 3. 解压（点击"操作" → "解压到当前目录"）
```

### 为什么最快？

1. **减少文件数**: 1000 个 → 1 个
2. **减少请求数**: 1000 次 → 1 次
3. **压缩传输**: 200MB → 50MB
4. **服务器解压**: 比逐个上传快 10-20 倍

### 适用场景

- ✅ 首次部署网站
- ✅ 文件数量 > 100 个
- ✅ 总大小 > 50MB
- ✅ 网络速度慢

## 💻 方案四：rsync 命令（最专业）

### 基础用法

```bash
# 增量同步（只传输变化的文件）
rsync -avz -e "ssh -p 22" \
  /local/website/ username@server:/home/www/
```

### 高级用法

```bash
# 删除服务器多余文件
rsync -avz --delete -e "ssh -p 22" \
  /local/website/ username@server:/home/www/

# 排除特定文件
rsync -avz \
  --exclude='*.log' \
  --exclude='node_modules/' \
  -e "ssh -p 22" \
  /local/website/ username@server:/home/www/

# 显示进度
rsync -avz --progress -e "ssh -p 22" \
  /local/website/ username@server:/home/www/
```

### 自动化脚本

```bash
#!/bin/bash
# deploy.sh

rsync -avz --delete \
  --exclude='.git/' \
  --exclude='node_modules/' \
  -e "ssh -p 22" \
  /local/website/ user@server:/home/www/

echo "部署完成！"
```

### 特点

- ✅ 速度最快
- ✅ 增量同步
- ✅ 可自动化
- ✅ 支持脚本
- ✅ 适合 CI/CD

### 适用场景

- ✅ 熟悉命令行
- ✅ 自动化部署
- ✅ 超大型网站（> 10GB）
- ✅ CI/CD 集成

### 注意事项

- ❗ Windows 需要安装 Git Bash 或 WSL
- ❗ Mac/Linux 系统自带
- ❗ 需要 SSH 访问权限

## ⚠️ 注意事项

### 通用注意事项

1. **首页文件名**: 必须是 `index.html`（小写）
2. **文件权限**: 上传后自动设置为 644（文件）、755（目录）
3. **空间限制**: 注意查看剩余空间
4. **文件编码**: 建议使用 UTF-8
5. **备份**: 重要文件请先备份

### 压缩包上传注意事项

1. 支持格式: `.zip`, `.tar.gz`, `.tar`, `.7z`
2. 解压会覆盖同名文件
3. 确保压缩包内有 `index.html`

### rsync 注意事项

1. Windows 需要安装 Git Bash 或 WSL
2. 需要 SSH 访问权限
3. `--delete` 参数会删除服务器多余文件，请谨慎使用
