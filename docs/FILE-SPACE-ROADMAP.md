# 文件空间 · 功能路线图

> 当前版本：v4.0（Liquid Glass 主题 + macOS Finder 布局）
> 已完成效率类：列表排序 / 键盘快捷键 / 移动到文件夹 / 拖拽移动 / 深色模式手动开关

---

## 一、查看与预览（纯前端，无后端改动）

| 功能 | 描述 | 难度 |
|------|------|------|
| 文件详情面板 | 点击文件右侧出现 Finder 风格「显示简介」侧面板：大小、修改时间、路径、MIME 类型、缩略图 | ⭐⭐ |
| Quick Look 只读预览 | 代码/文本文件按空格键弹出只读预览弹窗（不进编辑器），类似 macOS Quick Look | ⭐⭐ |
| 更多预览类型 | 视频（video 标签）、音频（audio）、PDF（embed/iframe）、Markdown 渲染预览 | ⭐⭐ |
| 图片画廊模式 | 预览图片时左右箭头切换同目录下一张/上一张，支持手势滑动 | ⭐⭐ |

---

## 二、分享与协作（需后端新增接口 + 数据库表）

| 功能 | 描述 | 难度 |
|------|------|------|
| 生成分享链接 | 单文件/文件夹生成临时链接，支持：有效期（1小时/1天/7天/永久）、访问密码、下载次数限制 | ⭐⭐⭐ |
| 文件二维码 | 分享链接生成后同步显示二维码，手机扫码直接下载/查看 | ⭐⭐ |
| 分享管理列表 | 侧栏或独立页面查看所有已创建的分享链接，可撤销/续期 | ⭐⭐ |

**后端设计要点：**
- 新增 `shares` 表（id, auth_code, file_path, token, password_hash, expire_at, max_downloads, download_count, created_at）
- 新增路由：`POST /share/create`、`GET /share/:token`（公开访问/下载）、`POST /share/list`、`POST /share/revoke`
- 公开访问路由不走 auth_code 校验，靠 token + password 鉴权

## 三、筛选与查找（前端为主，后端可选优化）

| 功能 | 描述 | 难度 |
|------|------|------|
| 按类型筛选 | 工具栏增加筛选器下拉：图片/文档/压缩包/视频/代码，组合搜索关键词使用 | ⭐ |
| 全空间搜索 | 搜索入口加「搜索整个空间」选项（当前已有「包含子文件夹」，可扩展为从根目录递归） | ⭐ |
| 收藏/快速访问 | 侧栏可固定常用文件夹，存在 localStorage，点击直达 | ⭐⭐ |
| 最近访问记录 | 记录最近打开/编辑的 10 个文件，侧栏快速跳转 | ⭐ |

## 四、下载与批量（需后端配合）

| 功能 | 描述 | 难度 |
|------|------|------|
| 打包下载到本地 | 批量选中后点击「下载」，后端打成 zip 流式返回到浏览器（不留在服务器上） | ⭐⭐⭐ |
| 文件夹整体下载 | 右键文件夹 →「下载为 ZIP」，同上 | ⭐⭐ |
| 断点续传下载 | 大文件下载支持 Range 请求，中断后可继续 | ⭐⭐⭐ |

**后端设计要点：**
- 新增 `POST /download` 接口，接收 paths 数组，服务端 `zip` 打包后 pipe 到 response（不落盘）
- 单文件可直接 302 到静态文件地址（已有 siteUrl 机制）

## 五、安全与记录（后端为主）

| 功能 | 描述 | 难度 |
|------|------|------|
| 自助修改授权码 | 用户端设置入口，验证旧码后可自行修改（后端更新 ftp 表 auth_code 字段） | ⭐⭐ |
| 操作历史记录 | 轻量版：记录最近 50 条操作（上传/删除/重命名/移动），前端弹出面板查看 | ⭐⭐ |
| 回收站 | 删除文件不立即移除，移入 `.trash` 隐藏目录，支持 7 天内恢复 | ⭐⭐⭐ |
| 2FA 双因素验证 | 高安全需求用户可选 TOTP 验证（Google Authenticator 等），登录时额外验证 | ⭐⭐⭐⭐ |

| 功能 | 描述 | 难度 |
|------|------|------|

## 优先级建议

按「用户价值 / 实现成本」比排序，推荐下一批实施顺序：

1. **按类型筛选 + 全空间搜索**（改动小，搜索体验立刻提升）
2. **Quick Look 只读预览 + 图片画廊**（纯前端，视觉体验拉满）
3. **打包下载到本地**（用户高频需求，需后端配合但逻辑简单）
4. **生成分享链接 + 二维码**（差异化功能，商业价值高）
5. **操作历史 + 回收站**（安全性兜底，减少误操作投诉）
