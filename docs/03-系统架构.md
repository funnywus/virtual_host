# 系统架构

## 整体架构

系统采用前后端分离架构，生产环境可由后端统一托管前端静态资源。

```
┌─────────────────────────────────────────────────────────┐
│                      浏览器客户端                         │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐  │
│  │ 管理后台 Vue  │  │ 公开上传页    │  │ Xterm 终端   │  │
│  └──────┬───────┘  └──────┬───────┘  └──────┬───────┘  │
└─────────┼─────────────────┼─────────────────┼──────────┘
          │ HTTP/WS           │ HTTP            │ HTTP/WS
          ▼                   ▼                 ▼
┌─────────────────────────────────────────────────────────┐
│              Node.js Express 后端 (server.js)           │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────────┐  │
│  │  Routes │ │Services │ │Middleware│ │ Worker Pool │  │
│  └────┬────┘ └────┬────┘ └─────────┘ └─────────────┘  │
│       │           │                                     │
│  ┌────▼───────────▼────┐    ┌──────────────────────┐   │
│  │   SQLite / MySQL    │    │  WebSocket Services  │   │
│  └─────────────────────┘    │  SFTP Proxy / SSL Log│   │
│                              └──────────────────────┘   │
└─────────────────────────┬───────────────────────────────┘
                          │ SSH / SFTP / DNS API
          ┌───────────────┼───────────────┐
          ▼               ▼               ▼
   ┌────────────┐  ┌────────────┐  ┌────────────┐
   │ Linux 服务器│  │ 阿里云 DNS  │  │ 腾讯云 DNS  │
   │ Nginx/FTP  │  │            │  │            │
   └────────────┘  └────────────┘  └────────────┘
```

## 后端模块划分

### 路由层 (`backend/routes/`)

| 路由前缀 | 文件 | 职责 |
|----------|------|------|
| `/api/auth` | `auth.js` | 登录、注册 |
| `/api/servers` | `servers.js` | 服务器 CRUD、连接测试 |
| `/api/dns` | `dns.js` | 域名、子域名、DNS 记录、DNS 平台 |
| `/api/users` | `users.js` | 用户管理 |
| `/api/ftp` | `ftp.js` | FTP 账号管理 |
| `/api/nginx` | `nginx.js` | Nginx 配置同步 |
| `/api/upload` | `upload.js` | 文件上传与管理（授权码模式） |
| `/api/upload-chunked` | `upload-chunked.js` | 分片上传 |
| `/api/ssl` | `ssl.js` | SSL 证书申请与状态 |
| `/api/tags` | `tags.js` | 服务器标签 |
| `/api/system` | `system.js` | 系统设置 |

### 服务层 (`backend/services/`)

| 服务 | 说明 |
|------|------|
| `ssh-ftp.js` | SSH 连接与 SFTP 文件操作 |
| `ssh-connection-pool.js` | SSH 连接池，减少重复握手 |
| `aliyun-dns.js` / `tencent-dns.js` | DNS API 封装 |
| `nginx-config.js` | Nginx 虚拟主机配置生成 |
| `ssl-cert.js` | SSL 证书申请与续期逻辑 |
| `ws-sftp-proxy.js` | WebSocket SFTP 代理 |
| `ssl-log-ws.js` | SSL 操作日志 WebSocket 推送 |
| `deploy-upload-script.js` | 部署 PHP 直传脚本到目标服务器 |
| `upload-system-files.js` | 系统文件上传辅助 |

### 数据库层 (`backend/db/`)

- `database.js` — MySQL 入口
- `database-mysql.js` — 连接池与查询封装
- 启动时自动执行 `migrateDatabase()` 补充缺失字段

## 关键数据流

### 创建子域名

```
用户提交 → DNS API 创建解析记录 → 写入 subdomains 表
        → SSH 生成 Nginx 配置 → 可选创建 FTP 账号
        → 可选申请 SSL 证书
```

### 文件上传（网页）

```
浏览器 → POST /api/upload/auth（授权码验证）
       → POST /api/upload/upload-file（Multer 接收）
       → SSH/SFTP 写入目标服务器目录
```

### 分片上传（大文件）

```
浏览器 → POST /api/upload-chunked/init（初始化）
       → POST /api/upload-chunked/chunk（逐片上传）
       → POST /api/upload-chunked/merge（合并后 SFTP 传输）
```

## 定时任务

后端启动后注册以下定时逻辑（见 `server.js`）：

- **SSL 证书检查** — 每日凌晨 3 点检查所有域名证书状态
- **子域名到期检查** — 自动停用过期子域名并清理 DNS 记录

## 性能相关配置

- 请求体大小限制：**500MB**
- 请求超时：**30 分钟**（支持大文件合并）
- Node 堆内存：**2GB**（`--max-old-space-size=2048`）
- 文件操作 Worker 池：异步处理 SSH 重操作，避免阻塞主线程
